# 开发者入门教学工作台（2026-10-18）

## 本次修复与教学内容

旧页面将滑块保存在普通 Python 对象里，或在渲染函数中创建再读值，导致 UI 依赖未被正确追踪。
现在每章的 `make_controls()` 返回顶层 `mo.ui.dictionary`；创建、显示、读取 `.value` 计算结果分别放在不同 cell。
六章各自保留 UI 状态，切章不会重新创建控件。滑块松手后更新，避免每个拖动像素都排队计算。
部分参数只影响指标而不改变图像（如累积次数、方差项权重），页面明确解释原因。

每章补齐：

- 具体学习目标和先修知识；中英文术语对照。
- 从数组/距离/均值开始的公式推导、输入输出形状与单位。
- 可调节的合成实验、联动图和当前计算读数。
- 正在生成图表的 `compute(values)` 实际代码与中文注释。
- 完整本章 Python 源码、可直接调用的最小示例及正式实现的只读源码。
- 带预期观察结果的练习、常见错误和下一章的连接。

删除了教学页面中硬编码的注意力耗时、ADE 曲线和无来源的鲁棒性结论。
第 4 章另行加载正式阶段 4 指标并显示来源、split、seed；不跨条件混算。
第 5 章明确仅为退化输入实验，正式三模型鲁棒性指标仍缺失。
教学页不再每次重绘都创建随机神经网络来宣称“实测模型能力”。

第 1 章通道与几何已对齐正式数据：0 道路/标线，1 静态边界要素，2 其他交通参与者（排除自车），3 可见性；中心为 (63.5,63.5)。
第 5 章使用不同的动态历史帧演示连续丢帧，而非重复四张一样的图；遮挡同步清空 visibility。
对应算子不是相机真实光学模型，边界随机像素删除也不等同于真实车道线磨损。
