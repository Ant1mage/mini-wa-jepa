# Stage 3 protocol (fixed before the formal run)

Authorization: the user confirmed “继续吧” after the completed stage 2 report. Stage 3 ends at its report; stage 4 is not authorized.

Use only the accepted v2 100k/10k/10k dataset. Pairs are adjacent 0.1s observations with matching episode IDs and consecutive step IDs, including noisy/recovery observations and terminal-failure targets where present. No future state, future action, navigation or trajectory label enters the model. No action head, EMA encoder, rollout, degrader or closed-loop policy is implemented in this stage.

Architecture: two stride-2 convolutions produce 32×32 stem features; a learned 4×4 patch projection gives 8×8 tokens. Six original pre-norm Transformer blocks use d=256, four heads and an MLP width of 1280. Encoder budget: 6–8M. A six-block d=384 residual predictor conditions on current speed/yaw rate and starts at exact copy-current. Encoder plus single-step predictor must remain within 15–30M. Functional PyTorch SDPA uses the MATH backend on native ROCm; no external model source, weights, compile or custom kernels.

Both encoder branches receive gradients. Apply prediction MSE plus explicit VICReg variance and off-diagonal covariance penalties directly to the actual encoder tokens, without a separate projector. To prevent a fixed positional pattern from satisfying the variance/rank test, subtract each token position's batch mean before computing the D×D covariance. Divide by N(B−1), averaging the unbiased per-position channel covariance. Weights are 25/25/1, gamma=1 and epsilon=1e−4, fixed in `configs/stage3.py`. This adapts the batch-axis VICReg statistics to spatial token data; it is not a claim of reproducing the original image-augmentation experiment.

Primary health metric: covariance entropy effective rank `exp(−sum(p log p))`, where p are the normalized eigenvalues of the content covariance. Its theoretical channel upper bound is D=256 (evaluation uses many more independent observations than channels). The primary rank ratio removes fixed-position means across the entire evaluation set, not per batch. Also disclose the uncorrected token rank, frame-pooled rank, channel standard deviations, eigenvalue spectrum and participation rank. No whitening/PCA transform is used before the acceptance rank calculation. PCA is diagnostic only; predictions and targets always use the same fitted basis.

Use 12 epochs, seed 20261017, batch 64 and AdamW/cosine learning rate, with bf16 training and FP32 validation. Validation uses a fixed seed-selected set of 4096 pairs. Select the checkpoint with the lowest validation prediction/copy MSE ratio among checkpoints with primary rank ratio >=0.75. If no checkpoint qualifies, select minimum validation VICReg loss and report the failed rank gate. Test is evaluated once after selection, using every valid test pair. Retain an untrained validation reference and the copy-current baseline with the same encoder, target and samples.

Acceptance: primary content rank ratio >=0.75 in each of the last three validation epochs and on the selected test checkpoint; prediction/copy MSE <=0.95 on test, with the upper end of the 95% episode-cluster bootstrap interval for paired MSE difference below zero. The 5% minimum gain makes the otherwise qualitative word “significant” explicit before training. Also disclose normalized errors and the exact copy MSE so a near-constant latent cannot pass by reporting a small raw MSE. Samples are correlated within episodes, so confidence intervals resample entire episodes, not individual adjacent frames. This is a single-seed representation experiment and does not establish downstream planning performance.

Preserve nonfinite/OOM/native failures with a failing batch/checkpoint MRE; stop on a nonfinite loss/gradient, or severe measured degeneration (content rank <2 or mean content std <0.01 after an epoch). A threshold miss without severe degeneration is still a failed stage gate, not permission to tune on test or start stage 4.

Every 400 optimizer steps and at epoch end, fixed validation sample IDs and visualization seed produce actual predicted/true latent arrays (`.npz` and `.rrd`), BEVs, prediction/target/error heatmaps and shared-basis PCA. Training global_step aligns with TensorBoard/Rerun; simulation time and sample IDs are separately recorded. Final artifacts include rank/std/eigenvalue curves, PCA, acceptance video and Marimo measured reports. ADE/FDE and closed-loop metrics remain missing because no action head exists.

Method references (equations only; implementation is original): [VICReg paper](https://arxiv.org/abs/2105.04906), [Roy & Vetterli, effective rank](https://infoscience.epfl.ch/bitstreams/9a5f3153-5c5d-4845-ab41-962296ec93ac/download). Effective rank here is applied to the covariance matrix itself; it must not be confused with the larger entropy rank obtained by taking square roots of its eigenvalues.
