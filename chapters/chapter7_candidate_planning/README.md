# Chapter 7：生成、评分和真实执行

在项目根目录运行：

```bash
.venv/bin/marimo run chapters/chapter7_candidate_planning/app.py
```

主课程 `app.py` 也有本章入口。所有控件由上游 cell 创建，画面由下游 cell 读取；本章只回放冻结数据，不会启动训练或仿真。

- 生成页展示冻结模型在固定测试起点的真实 10 步 Flow 积分，0 是噪声，10 是最终候选；积分进度不是车辆行驶时间。
- 规划页从单个实际 NPZ 读取全部候选、分项成本、选择、控制和实际行驶，拖动或方向键逐步查看后续重新规划。
- `STOP` 是所有候选均被拒绝时的规则刹停，不是 Flow 生成或自主选中的候选。
- 正式成绩来自 `artifacts/restart_stage7/REPORT.md`，没有成绩时保持缺失；冒烟记录明确标注。

研究记录使用公共 RerunLogger。未执行候选没有真实反事实目标，不能把潜变量画成未来道路图像。课程模块与代码展示均只读。
