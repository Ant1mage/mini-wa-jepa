# Chapter 4 · 把世界预测与轨迹预测接起来

面向入门开发者，先修知识：十点轨迹、归一化、潜变量预测。

## 学习目标

解释4帧历史/4步潜变量/10点轨迹；读懂先验+学习残差；分清Joint与Action-only。

本章分成三个小实验，每次围绕一个问题操作控件、观察图示与解释；中文注释代码、深入原理和正式源码可以按需展开。
可以调节：速度、角速度、手工横向修正与高亮未来时刻。拖动滑块即更新旁边图示与解释；在总入口切换章节会保留各章参数。

## 打开与阅读代码

```bash
# 从仓库根目录运行
.venv/bin/marimo edit chapters/chapter4_joint_world_action/app.py
# 也可 ./start.sh 打开七章统一入口
```

`app.py` 将控件创建与消费分成独立 cell；`ui.py` 内的 `compute(values)`
是页面展示的实际计算代码，包含中文注释。
页面还提供完整本章 Python 源码和最小调用示例；`src/` 的原有模型/训练实现保留，
但教学版本不保证兼容正式训练 checkpoint。正式实验不由滑块启动。

## 先做这道练习

速度10、角速度0，检查2秒位置(20,0)；转向变号后侧向位移应对称。

## 结果边界

先验调用正式数学函数，残差为手工示例。独立指标表读取磁盘报告并带来源；缺失保持缺失。

进一步阅读：models/joint.py、training/joint_loss.py、configs/stage4.py。共享展示工具位于 `chapters/learning.py`，
不参与正式训练。完整课程说明见上级 `chapters/README.md`。
