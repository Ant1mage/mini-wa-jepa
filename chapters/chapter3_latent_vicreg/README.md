# Chapter 3 · 理解潜变量预测与 VICReg

面向入门开发者，先修知识：均值、平方误差和二维数组。

## 学习目标

理解常数输出塌缩；读懂方差与协方差；知道低预测误差不足以证明表示有用。

本章分成三个小实验，每次围绕一个问题操作控件、观察图示与解释；中文注释代码、深入原理和正式源码可以按需展开。
可以调节：特征幅度、共享比例、预测噪声、方差权重和样本数。拖动滑块即更新旁边图示与解释；在总入口切换章节会保留各章参数。

## 打开与阅读代码

```bash
# 从仓库根目录运行
.venv/bin/marimo edit chapters/chapter3_latent_vicreg/app.py
# 也可 ./start.sh 打开七章统一入口
```

`app.py` 将控件创建与消费分成独立 cell；`ui.py` 内的 `compute(values)`
是页面展示的实际计算代码，包含中文注释。
页面还提供完整本章 Python 源码和最小调用示例；`src/` 的原有模型/训练实现保留，
但教学版本不保证兼容正式训练 checkpoint。正式实验不由滑块启动。

## 先做这道练习

特征幅度设0，观察MSE=0但方差惩罚仍大；共享比例设1，观察通道重复。
